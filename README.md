# Asset Controller System (ACS)

A web-based asset management system developed to streamline asset request and update processes for staff in a more organized, efficient, and systematic way.

## 💻 Project Overview

Asset Controller System (ACS) is a Laravel-based web application designed to simplify asset application management within an organization. The system allows staff to submit asset requests through a structured digital platform while enabling administrators to manage, monitor, and generate reports efficiently.

The system includes predefined asset category codes to standardize asset requests and improve asset tracking accuracy.

---

## ✨ Key Features

### 👨‍💼 Staff Features
- Staff Registration & Login
- Submit Asset Requests
- Update Asset Information
- View Request Status
- Organized Asset Category Selection

### 🛡️ Admin Features
- Admin Dashboard
- Manage Staff Requests
- Monitor Asset Applications
- Approve or Reject Requests
- Generate Request Reports
- Print Reports
- Export Reports to Excel
